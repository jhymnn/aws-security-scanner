# AWS Security Scanner
KISA 가이드라인 기반 클라우드 보안 진단 및 생성형 AI 리포팅 시스템

# 프로젝트 소개
AWS 환경에서 보안 설정을 자동으로 점검하는 시스템입니다. IAM, S3, RDS, CloudTrail 등 주요 서비스를 대상으로 취약점을 탐지하고 Security Score를 계산합니다.

AWS 클라우드 환경에서 보안 취약점을 자동으로 탐지하고, 국내 정보보호 기준에 맞추어 보안 상태를 진단하며, 생성형 AI 를 활용하여 사용자 친화적인 보안 리포트를 자동 생성하는 것을 목표로 한다. 기존의 단순 취약점 탐지 도구와 달리, 본 시스템은 단순히 보안 설정의 이상 여부를 알려주는 것에서 그치지 않고, 취약점의 원인, 위험성, 개선 방안까지 자연어 형태로 설명함으로써 실제 활용 가능한 보안 컨설팅 도구의 역할까지 수행하도록 설계되었다.
